# PhishGuard AI — Project Abstract

**Project Title:** PhishGuard AI – Real-Time Phishing Message Detection System  
**Domain:** Cyber Security / Applied Machine Learning / Natural Language Processing  

### Abstract

The widespread adoption of mobile banking, digital payments, and multi-factor authentication has made Short Message Service (SMS) and mobile messaging a primary target for cyber adversaries. SMS phishing, or **smishing**, exploits human cognitive vulnerabilities—such as urgency, fear, and curiosity—alongside technical evasion tricks like shortened URLs to deceive users into surrendering sensitive credentials and financial information. Traditional spam filters and keyword blocklists often fail against concise, targeted attacks and operate as uninterpretable black boxes without guiding users on safe responses.

**PhishGuard AI** addresses this challenge by introducing a multi-layered hybrid cyber defense system. The architecture synthesizes Natural Language Processing (NLP) with statistical machine learning and deterministic heuristic layers. Incoming text messages undergo text preprocessing and Term Frequency-Inverse Document Frequency (TF-IDF) feature extraction, followed by probability estimation using regularized Logistic Regression. In parallel, a defensive URL analysis engine passively inspects embedded links for URL shorteners, raw IP addresses, and suspicious domains without resolving external servers, while a social engineering engine flags psychological manipulation tactics. A composite Risk Scoring Engine combines these analytical signals into an intuitive 0–100 risk score and 4-tier threat level, delivering human-readable explanations and actionable security recommendations.

The platform is implemented using a Python Flask REST API backend and a responsive React 19 web frontend featuring manual scanning, live dashboard telemetry, persistent local audit history, and an interactive real-time simulation tab. For native mobile environments, an Android companion module foundation is architected using the `SMS_RECEIVED` system broadcast. The baseline classifier was trained on the benchmark UCI SMS Spam Collection dataset (5,572 messages; 80/20 stratified split), achieving **97.58% test accuracy on the UCI SMS Spam Collection baseline**. While the system does not claim perfect real-world phishing detection and recognizes constraints regarding static heuristics and platform sandboxing, PhishGuard AI provides a practical, low-latency, and explainable defense-in-depth framework for modern mobile messaging security.
